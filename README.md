I enjoy building end-to-end solutions, working across the entire stack. From designing intuitive front-end interfaces to architecting back-end systems. My main focus lies in building cloud native applications in AWS to deliver reliable and efficient software.

# Company Experiences

Right now I work at LevarneBV, where I build applications for a range of clients, including cash management systems, customer dashboards, and internal tools. Among the things I've worked on, I'm especially proud of my contributions to our internal accelerator, a shared foundation that handles auth, logging, and hosting for our SaaS products. I've also built other things along the way, like an emulator for one of our client's cash machines.

Master's Thesis Research Internship at Elsevier Research collaboration unit. Developed a workflow for analysing software usage by creating communities from a co-occurrence network of software mentions. Technologies used: Databricks, pandas, Snowflake's Arctic-embed-s, and igraph.

Software Developer project for Lifewatch. LifeWatch is a group that provides a virtual research environment. We designed, implemented, and evaluated a cloud extension built on AWS that provided on-demand, elastically scalable compute for Jupyter notebook workloads. The system used a serverless API layer of AWS Lambda functions behind API Gateway, AWS Batch for job execution on EC2 and Fargate instances, Amazon S3 for all storage, and AWS CloudWatch for observability. Infrastructure was fully managed through Terraform with a remote state backend, and a GitHub Actions CI/CD pipeline automates validation, container builds, and deployment.

Software Developer project for the company Contentkalender as part of my Computer Science end project. The ContentKalender develops a web-based content calendar application. We Developed an extension to the ContentKalender as part of our graduation projects for the Bachelor's computer science. We extended the application by developing an integration hub that enables users to synchronize their tasks with Google Tasks and Microsoft To Do, synchronize communications with Microsoft Planner, and receive Contentkalender notifications directly in Microsoft Teams through a notification bot.
